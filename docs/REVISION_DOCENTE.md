# Revision docente - MIRAGE

## Arquitectura
Interfaz React y Vite.
Servidor Express con API REST.
Base de datos PostgreSQL.
Autenticacion mediante JWT.
Integracion de asistente de IA.

## Funcionalidades a demostrar
- Registro e inicio de sesion.
- Gestion de eventos.
- Administracion de invitados.
- Seguimiento de presupuestos.
- Consulta de historial.
- Asistente de recomendaciones.

## Verificacion
Ejecutar npm test y npm run build.

## Requisitos de ejecucion
La aplicacion de escritorio puede requerir el servidor,
las variables de entorno y PostgreSQL configurados.
No publicar contrasenas ni claves privadas.
